# Polices pour l'image de partage

`ShareImage` dessine l'image Open Graph avec GD, qui lit des fichiers TTF (les woff2 de `public/fonts` servent au navigateur).

- `cormorant-garamond-600.ttf` : Cormorant Garamond, SIL Open Font License 1.1
- `dm-sans-400.ttf`, `dm-sans-600.ttf` : DM Sans, SIL Open Font License 1.1

Source : Google Fonts. Ces fichiers ne sont jamais servis au public.
